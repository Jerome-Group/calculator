# Public MIT source

Calculator uses the organisation's public template, like the three mathematics sites, so its source can be inspected, run and adapted. MIT grants these rights for owned application source and educational material. The shared template's licence is unchanged.

Dependencies retain their existing licences and notices. Bundled Pyodide remains MPL-2.0 with upstream source availability, and scientific libraries retain their own terms. The grant does not relicense vendored material.

The first public import is a reviewed source snapshot. Original development commits remain in a local archival ref. Credentials, private build prompts, personal notebooks and authenticated browser/tool state remain outside the public tree and public history.

The portable Working folder is the application checkout. The mini administers the org; its previous Calculator checkout was removed after content and history verification. Fresh Sites registration binds this source to the current account, without copying the old Site's users or database records.
